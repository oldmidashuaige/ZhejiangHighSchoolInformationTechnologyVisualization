# 算法可视化教学平台

面向浙江高中信息技术学考/选考开发的算法可视化教学工具，把 18 个算法做成动画演示：排序（冒泡/选择/插入）、查找（顺序/二分）、递归（阶乘/斐波那契/汉诺塔/最大公约数）、数据结构（链表/队列/栈/二叉树/哈希表）、其他（进制转换/凯撒密码/贪心/SQL）。

## 使用
- 最建议使用安装包`releases/tag/v1.0.0_EXE_setup`安装应用
- 也可以下载 `releases/tag/v1.0.0/v1.0.0.html` 离线版网页运行；或运行 `releases/tag/v1.0.0免安装应用` 里的免安装版 exe
- 支持播放/步进/变速回放、Python 代码联动、分步讲解、复杂度与考点总结

## 开发
- `npm install && npm run dev`：本地开发
- `npm run build`：构建网页（输出 `dist/index.html`）
- `npm run dist`：打包 Windows 安装版与免安装版
